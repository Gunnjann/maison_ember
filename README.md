## About the Project

Maison Ember is a full-stack restaurant website designed around an elegant dining experience. The project combines a refined visual identity with a modern web architecture to create an engaging online presence for a fine-dining restaurant.

## Features

- **Elegant Interface** — A premium restaurant-inspired design.
- **Interactive Menu** — A digital menu experience powered by an Express API.
- **Responsive Layout** — Designed to work across desktop and mobile screens.
- **Modern Architecture** — React and Vite frontend with a separate backend.
- **Live Deployment** — Hosted on Vercel.

## Getting Started

### Prerequisites

- Node.js
- npm

### 1. Clone the repository

```bash
git clone https://github.com/Gunnjann/Maison-Ember.git
cd Maison-Ember
```

### 2. Start the frontend

```bash
cd client
npm install
npm run dev
```

### 3. Start the backend

Open another terminal:

```bash
cd server
npm install
npm run dev
```

The frontend and backend run separately. Check the server configuration for the API port and environment variables required by your local setup.
